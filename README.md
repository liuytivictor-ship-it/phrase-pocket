# Phrase Pocket · 英语表达收藏夹

一个可离线使用的个人英语表达收藏和复习网站。使用原生 HTML、CSS 和 JavaScript，没有后端，也不需要安装依赖。

## 功能

- 添加英语表达、中文释义、使用情境
- 搜索英语、中文和备注
- 按“全部 / 学习中 / 已掌握”筛选
- 每条表达可点 ☆ 收藏、点 ⭐ 取消收藏，刷新后保留星标
- “⭐ 只看收藏”开关可与搜索、掌握状态筛选叠加使用
- 标记已掌握、删除表达
- 随机抽取卡片复习，可点击显示释义
- 浏览器 `localStorage` 自动保存（仅限当前浏览器和当前网站地址）
- v1.1：导出 JSON 备份，校验和预览后确认恢复

## 如何运行

下载 `index.html`，在电脑浏览器中直接打开即可。在本地环境中也可以通过 VS Code 的 Live Server 或 `python -m http.server 8000` 运行。

## 如何部署到 GitHub Pages

1. 新建名为 `phrase-pocket` 的 **Public** 仓库。
2. 上传 `index.html` 和 `README.md` 到仓库根目录并 Commit。
3. 打开 **Settings → Pages → Build and deployment**。
4. 在 **Source** 里选 **Deploy from a branch**，分支选 `main`，文件夹选 `/ (root)`，点击 **Save**。
5. 发布完成后，访问 `https://你的用户名.github.io/phrase-pocket/`。

> 注意：GitHub Pages 会公开展示网站。此程序的数据只储存在访问者浏览器本地，不会跨浏览器、设备或域名同步。清理浏览器站点数据可能清除收藏。

## v1.1：备份与恢复

### 导出备份

在“数据备份”区域点击“导出备份”。导出的 JSON 包含**全部表达**的英语、中文、备注、掌握状态、星标状态和 ID，不受当前搜索或筛选影响，也不会修改表达库。

- 电脑通常会下载 `phrase-pocket-backup-日期时间.json`。
- iPhone Safari 和主屏幕网页 App 支持文件分享时，会打开系统分享菜单；请选择“存储到文件”，再确认保存位置。取消分享不会修改数据。
- 不支持文件分享时使用普通下载；页面也会保留“下载 JSON 文件”链接，可再次点击保存。请到“文件”App 或浏览器下载目录确认文件存在，再清除网站数据或更换设备。

### 导入备份

1. **先导出当前数据**，保留一份可恢复的文件。
2. 点击“导入备份”，在系统文件选择器中选择此前导出的 JSON 文件。
3. 程序检查整个文件，显示表达总数、掌握数、星标数，以及当前将被替换的记录数。此时没有修改数据。
4. 点击“替换并恢复”后，还需要在确认框中确认；点击“取消导入”或取消确认框都会保留原数据。
5. 恢复成功后，刷新页面检查内容。搜索和筛选会重置，旧的复习卡片会清除，避免显示已被替换的表达。

**恢复是替换，不是合并，也没有自动撤销。** 空备份可以恢复，但会明确提示将清空表达库。Safari 和主屏幕网页 App 的存储可能不同，请在需要恢复数据的入口执行导入。

### 格式与数据安全

备份使用以下格式；格式版本 `1` 与功能版本 `v1.1` 是两个不同的编号：

```json
{
  "app": "phrase-pocket",
  "version": 1,
  "exportedAt": "2026-10-15T08:00:00.000Z",
  "phrases": [
    {
      "id": "example-id",
      "english": "It's worth a shot.",
      "meaning": "值得一试。",
      "notes": "鼓励自己尝试时使用。",
      "mastered": false,
      "favorite": true
    }
  ]
}
```

- 导入和导出文件上限为 5 MiB（界面简写为 5 MB），不截断记录。超限会报错，现有数据保持不变。
- 文件必须有正确的来源、格式版本、导出时间和表达数组。每条表达都必须有正确类型的完整字段；ID 必须非空且不能重复，英语和中文不能为空。旧版本地记录会按原有方式补全默认字段后导出；不把任意 JSON 数组当作备份。
- 文件损坏、记录无效或读取失败时，拒绝整个文件，不会跳过坏记录后覆盖表达库。备份文字按普通文本显示，不作为 HTML 执行。
- 确认后先进行一次 localStorage 写入，成功后才替换内存和页面；容量不足或浏览器拒绝存储时，不替换原数据。
- 预览后若当前页面或其他标签页修改了数据，恢复会停止，请重新选择备份核对数量。确认框关闭后也会再检查一次。
- 选择文件前，如果其他标签页已更新本地记录，也会阻止恢复预览。请先导出当前页面的数据，再刷新查看最新记录后重试。
- 备份在浏览器本地生成和读取，没有服务器、数据库、外部库或文件上传。备份文件本身不是加密文件，请保存在自己的位置。

### 这次代码怎么读

- **HTML**：新增备份按钮、原生文件选择框和默认隐藏的预览区域。`hidden` 控制是否显示，`role="status"` 帮助读屏软件读出结果。
- **CSS**：沿用现有面板、按钮和配色，使用 `flex-wrap` 让按钮在窄屏换行；新的操作按钮至少 44px 高，便于触摸。
- **JavaScript**：`JSON.stringify()` 打包数据；`File` 和下载链接生成文件，支持时调用系统分享。`FileReader` 读取用户选中的文件，`JSON.parse()` 还原后逐条校验。
- **先准备，再提交**：校验后的表达先放进 `pendingImport`，如同一张待确认的草稿。取消只丢弃草稿。确认且存储写入成功后，才把草稿换成正式数据；所以预览和取消都不会动原记录。

### 自动测试与 iPhone 验收

网站本身仍然只需打开 `index.html`，不需要安装依赖。自动测试使用 Node.js 内置测试工具和开发环境提供的 Playwright，不会加载到网站：

```sh
node --test tests/backup.test.cjs
```

开发环境需要能解析 `playwright` 包，默认使用 `/usr/bin/chromium`；其他路径可通过 `CHROMIUM_PATH` 指定。已安装 Playwright WebKit 时可运行 `TEST_BROWSER=webkit node --test tests/backup.test.cjs`。系统分享接口在自动测试中使用模拟，不能代替 iPhone 真机验收。

请在 iPhone Safari 和主屏幕网页 App 中分别检查：

1. 添加包含中文、备注的表达，修改掌握和星标状态；导出后在“文件”App 确认 JSON 已保存。
2. 选择此文件，核对预览数量；分别取消预览、取消最终确认，确认原数据不变。
3. 修改表达库后导入备份并确认；刷新或关闭后重新打开，确认内容、掌握和星标恢复。
4. 选择损坏文件，确认出现错误且数据不变；取消系统分享或文件选择也不应修改数据。

## 星标收藏如何工作

添加表达是把内容收进表达库；星标收藏是给其中想重点关注的表达做标记。新添加的表达默认未加星标，已有用户的旧记录也默认未加星标。

程序继续使用原有的 localStorage 键 `phrase-pocket-v1`，在每条记录里增加 `favorite: true / false`。读取旧数据时，没有这个字段就当作 `false`，原有英语、中文、备注和掌握状态保持不变。不需要手动迁移数据。

“只看收藏”只控制列表显示，不会删除或更改表达。刷新后星标仍在，筛选开关恢复关闭。添加新表达后会清除搜索和筛选，让新表达立即可见。随机复习继续优先抽取未掌握的表达，不受列表筛选影响。

### 给初学者的代码说明

- **HTML 是骨架**：筛选区的 `<button>` 是开关；每张卡片的星标按钮由 JavaScript 创建。`aria-pressed` 表示按钮是否开启，方便读屏软件识别。
- **CSS 是外观**：`.iconbtn.favorite[aria-pressed="true"]` 让收藏按钮显示暖色边框和背景。`@media(max-width:530px)` 让手机上的按钮另起一行，并扩大到 44 像素，便于触摸。
- **JavaScript 是行为**：点击星标后，用 `map()` 找到对应 `id` 的表达，切换 `favorite`，然后保存并重新显示列表。用 `filter()` 同时检查关键词、掌握状态和收藏状态，只显示符合全部条件的表达。
- **localStorage 是浏览器里的小抽屉**：`JSON.stringify()` 把表达数组转换成文字存进去；`JSON.parse()` 在下次打开时把文字还原成数组。它只保留在当前浏览器和网站地址里，不会自动同步到其他设备。

## 手工测试清单

1. 输入英语和中文，点击添加；页面出现新表达、总数 +1。
2. 刷新浏览器，刚刚添加的内容仍在。
3. 搜索关键词，过滤结果正确。
4. 点击 ✓，掌握统计变化，筛选“已掌握”可看到该表达。
5. 点击“抽取一句”，再点击“显示释义”，能看到中文。
6. 删除一条表达，刷新后仍然被删除。
7. 点一条表达的 ☆，按钮变为 ⭐；刷新后仍为 ⭐，其他内容及统计不变。
8. 点“⭐ 只看收藏”，只显示加星标的表达；再次点击恢复完整列表。
9. 在“只看收藏”开启时搜索英语、中文、备注，并切换“学习中 / 已掌握”，确认条件可以叠加。
10. 在收藏列表中取消最后一条收藏，显示空状态提示；关闭开关后该表达仍在。刷新后确认星标已取消。
11. 在“只看收藏”开启时添加新表达，确认筛选重置、新表达可见且默认未加星标。删除已收藏表达后刷新，确认没有残留记录。
12. 在旧版网站已有数据的同一浏览器、同一地址打开新版，确认内容和掌握状态保留，默认没有星标；先收藏再刷新，确认星标保存。
13. 在电脑及手机窄屏（如 320px、390px）操作以上功能，确认页面无横向溢出、按钮可点击。也可用 Tab 定位星标、用空格切换，确认焦点仍可继续操作。
