# Phrase Pocket · 英语表达收藏夹

一个可离线使用的个人英语表达收藏和复习网站。使用原生 HTML、CSS 和 JavaScript，没有后端，也不需要安装依赖。

## 功能

- 添加英语表达、中文释义、使用情境
- 搜索英语、中文和备注
- 按“全部 / 学习中 / 已掌握”筛选
- 每条表达可点 ☆ 收藏、点 ⭐ 取消收藏，刷新后保留星标
- “⭐ 只看收藏”开关可与搜索、掌握状态筛选叠加使用
- 标记已掌握、删除表达
- 随机抽取卡片复习，可点击显示释义
- 浏览器 `localStorage` 自动保存（仅限当前浏览器和当前网站地址）

## 如何运行

下载 `index.html`，在电脑浏览器中直接打开即可。在本地环境中也可以通过 VS Code 的 Live Server 或 `python -m http.server 8000` 运行。

## 如何部署到 GitHub Pages

1. 新建名为 `phrase-pocket` 的 **Public** 仓库。
2. 上传 `index.html` 和 `README.md` 到仓库根目录并 Commit。
3. 打开 **Settings → Pages → Build and deployment**。
4. 在 **Source** 里选 **Deploy from a branch**，分支选 `main`，文件夹选 `/ (root)`，点击 **Save**。
5. 发布完成后，访问 `https://你的用户名.github.io/phrase-pocket/`。

> 注意：GitHub Pages 会公开展示网站。此程序的数据只储存在访问者浏览器本地，不会跨浏览器、设备或域名同步。清理浏览器站点数据可能清除收藏。

## 星标收藏如何工作

添加表达是把内容收进表达库；星标收藏是给其中想重点关注的表达做标记。新添加的表达默认未加星标，已有用户的旧记录也默认未加星标。

程序继续使用原有的 localStorage 键 `phrase-pocket-v1`，在每条记录里增加 `favorite: true / false`。读取旧数据时，没有这个字段就当作 `false`，原有英语、中文、备注和掌握状态保持不变。不需要手动迁移数据。

“只看收藏”只控制列表显示，不会删除或更改表达。刷新后星标仍在，筛选开关恢复关闭。添加新表达后会清除搜索和筛选，让新表达立即可见。随机复习继续优先抽取未掌握的表达，不受列表筛选影响。

### 给初学者的代码说明

- **HTML 是骨架**：筛选区的 `<button>` 是开关；每张卡片的星标按钮由 JavaScript 创建。`aria-pressed` 表示按钮是否开启，方便读屏软件识别。
- **CSS 是外观**：`.iconbtn.favorite[aria-pressed="true"]` 让收藏按钮显示暖色边框和背景。`@media(max-width:530px)` 让手机上的按钮另起一行，并扩大到 44 像素，便于触摸。
- **JavaScript 是行为**：点击星标后，用 `map()` 找到对应 `id` 的表达，切换 `favorite`，然后保存并重新显示列表。用 `filter()` 同时检查关键词、掌握状态和收藏状态，只显示符合全部条件的表达。
- **localStorage 是浏览器里的小抽屉**：`JSON.stringify()` 把表达数组转换成文字存进去；`JSON.parse()` 在下次打开时把文字还原成数组。它只保留在当前浏览器和网站地址里，不会自动同步到其他设备。

## 手工测试清单

1. 输入英语和中文，点击添加；页面出现新表达、总数 +1。
2. 刷新浏览器，刚刚添加的内容仍在。
3. 搜索关键词，过滤结果正确。
4. 点击 ✓，掌握统计变化，筛选“已掌握”可看到该表达。
5. 点击“抽取一句”，再点击“显示释义”，能看到中文。
6. 删除一条表达，刷新后仍然被删除。
7. 点一条表达的 ☆，按钮变为 ⭐；刷新后仍为 ⭐，其他内容及统计不变。
8. 点“⭐ 只看收藏”，只显示加星标的表达；再次点击恢复完整列表。
9. 在“只看收藏”开启时搜索英语、中文、备注，并切换“学习中 / 已掌握”，确认条件可以叠加。
10. 在收藏列表中取消最后一条收藏，显示空状态提示；关闭开关后该表达仍在。刷新后确认星标已取消。
11. 在“只看收藏”开启时添加新表达，确认筛选重置、新表达可见且默认未加星标。删除已收藏表达后刷新，确认没有残留记录。
12. 在旧版网站已有数据的同一浏览器、同一地址打开新版，确认内容和掌握状态保留，默认没有星标；先收藏再刷新，确认星标保存。
13. 在电脑及手机窄屏（如 320px、390px）操作以上功能，确认页面无横向溢出、按钮可点击。也可用 Tab 定位星标、用空格切换，确认焦点仍可继续操作。
